Assignment 1: HBV001A Model Calibration
Results and Discussion


1. Calibration Outcome

The HBV001A lumped conceptual model was calibrated using Differential Evolution
(DE) optimization with the objective function OFV = 1 - NSE. The optimization
ran for 80 generations with a population size of 16, resulting in 22,032 total
model evaluations. The random seed was fixed at 42 for reproducibility.

Final Results:
  Nash-Sutcliffe Efficiency (NSE): 0.862218
  Objective Function Value (OFV): 0.137782

This NSE value of 0.86 falls in the "very good" category for lumped conceptual
hydrological models. In standard hydrology practice, NSE above 0.75 is
considered good, and NSE above 0.85 is considered very good.

Performance Metrics:
  Bias (mean of Sim - Obs): -1.06 m3/s
  RMSE: 9.56 m3/s

The negative bias indicates that, on average, the model slightly underestimates
discharge. However, this aggregate bias masks opposing errors at different flow
regimes, as discussed below.


2. Why NSE Does Not Reach 0.90

The NSE metric is defined as:

  NSE = 1 - [sum of (Sim - Obs)^2] / [sum of (Obs - mean(Obs))^2]

Because NSE uses squared errors in the numerator, large errors at individual
timesteps have a disproportionate impact on the final value. This mathematical
property explains why peak flow mismatches dominate the NSE calculation.

Peak Flow Analysis (Top 5 Observed Peaks):

  Observed [m3/s]   Simulated [m3/s]   Error [m3/s]   Relative Error
  ---------------------------------------------------------------------
      153.50            99.57            -53.93          -35.1%
      152.75            99.28            -53.47          -35.0%
      152.00            97.26            -54.74          -36.0%
      152.00            97.98            -54.02          -35.5%
      151.25            99.74            -51.51          -34.1%

The model underestimates the highest observed peaks by approximately 50 to 55
m3/s, which represents about 35 percent of the observed peak magnitude. When
these errors are squared (for example, 54 squared equals 2916), their
contribution to the NSE numerator becomes substantial.

Low Flow Analysis (Bottom 10 Percent of Flows):

  Threshold (10th percentile): 7.28 m3/s
  Mean observed: 5.08 m3/s
  Mean simulated: 8.46 m3/s
  Bias: +3.38 m3/s (model overestimates low flows)

In contrast to the peak flow underestimation, the model overestimates low flows
by about 3.4 m3/s on average. This opposing pattern explains why the overall
bias is only -1.06 m3/s despite the large peak errors.

Main Conclusion:

NSE does not reach 0.90 because the squared errors at extreme peak flows
dominate the calculation. The model structure of HBV001A, which is a lumped
conceptual model with simplified routing, cannot perfectly capture the rapid
rise and high magnitude of flood peaks. This is a structural limitation of the
model, not an optimization failure. The DE algorithm converged properly, as
evidenced by the flattening of the running best curve after approximately 60
generations.


3. Calibrated Parameters

The best parameter set includes some physically unusual values:

  sl0_pwp (Permanent Wilting Point): 665.01 mm
  sl0_fcy (Field Capacity): 113.61 mm

In physical terms, field capacity should exceed permanent wilting point.
However, the HBV001A model code does not enforce the constraint FCY > PWP.
During optimization, the algorithm found that this unusual configuration
minimizes the objective function. This indicates that the effective model
parameters may compensate for structural limitations rather than representing
true physical soil properties.

The following plots were generated to document the calibration process and

4.1 observed_vs_simulated.png

Purpose: Compare model output to observed discharge over the simulation period.

Top panel:
  X-axis: Time (datetime)
  Y-axis: Discharge in m3/s
  Black line: Observed discharge
  Blue line: Simulated discharge

Bottom panel:
  X-axis: Time (same as top)

Interpretation: The model captures the general seasonal pattern but
underestimates the major flood peaks in January. The residual panel shows
strong negative values during peak events and moderate positive values during
low flow periods.

  Shows the same metrics but includes the maximum (worst) objective per

Interpretation: Most improvement happens early in the optimization. After the
first 20 generations, gains become smaller and the running best curve flattens,
indicating the search has largely converged to a stable solution. The secondary
y-axis allows direct reading of NSE values.

4.4 internal_variables.png

Purpose: Visualize the internal states and fluxes of the HBV model.

Eight subplots from top to bottom:

1. Temperature [deg C]: Input forcing. Zero line shown for snow/rain threshold.
2. Precipitation [mm/hr]: Input forcing.
3. Snow depth [mm water equivalent]: Accumulated snow storage. Orange line on
   right axis shows melt rate.
4. Soil moisture [mm]: Water stored in soil. Green dashed line shows FCY
   (113.6 mm), red dashed line shows PWP (665.0 mm). The calibrated soil
   parameters give PWP greater than FCY. This is not physically typical, but
   the current HBV implementation does not enforce FCY > PWP.
5. Evapotranspiration [mm/hr]: Orange is potential ET, green is actual ET.
6. Reservoir storage [mm]: Blue is upper reservoir, dark blue is lower
   reservoir. Red dashed line shows urr_tdh threshold (101.9 mm).
7. Runoff components [mm/hr]: Surface runoff and reservoir contributions
   (URR and LRR combined).
8. Water balance [mm per timestep (hourly)]: Should be near zero if mass
   conservation holds.

Interpretation: The plots confirm proper model behavior. Snow accumulates
during cold periods and melts in warmer periods. The upper reservoir threshold
line helps identify when fast flow paths activate.

5. Optional Improvements (Within Assignment 1 Scope)

The following modifications could potentially improve results while staying
within Assignment 1 rules:

a) Multiple random seeds: Run DE with 3 to 5 different seeds and compare
   results to assess solution robustness.

b) Increased iterations: If computational time allows, increase maxiter beyond
   80 to explore whether further improvement is possible.

c) Polish option: Set polish=True in the DE call to apply a bounded local
   search (L-BFGS-B) after DE completes.

d) Alternative DE strategy: Try strategies like 'best2bin' or 'rand1bin'
   instead of 'best1bin'.

e) Population size: Increase popsize to improve exploration of parameter space.

These are optional and may yield only marginal improvements given that the main
limitation is model structure rather than optimization algorithm performance.


6. Summary

The HBV001A model was successfully calibrated using Differential Evolution,
achieving NSE = 0.862. This represents a very good fit for a lumped conceptual
model. The NSE does not reach 0.90 primarily because:

1. NSE uses squared errors, amplifying the impact of large mismatches
2. The model underestimates extreme flood peaks by 50 to 55 m3/s (about 35%)
3. The model overestimates low flows by about 3.4 m3/s
4. These systematic errors are structural limitations, not optimization failures

The calibrated parameters include physically unusual values (PWP > FCY), which
the model code allows but which may indicate parameter compensation rather than
true physical representation.
