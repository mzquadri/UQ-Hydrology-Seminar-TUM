Q4: Difference to Oudin et al. 2006?
----------------------------------------------------------------------
  Oudin et al. 2006 study:
  - Analyzed biased AND randomly corrupted inputs
  - Used multiple rainfall-runoff models (GR4J, TOPMO, HBV)
  - Found that model efficiency is more affected by random errors
    than by systematic bias
  - Showed that recalibration can partially compensate for input errors

  Our analysis (Assignment 4):
  - Uses only random perturbations C = N(1, 0.05) (no systematic bias)
  - Single model (HBV001A)
  - Similar findings expected: random noise affects model performance
  - Recalibration can compensate to some extent by adjusting parameters
